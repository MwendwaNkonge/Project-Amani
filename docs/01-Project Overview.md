# 🚀 Project Amani

## Core Banking Transformation Programme

### Data Migration Workstream

---

## 📖 Executive Summary

Project Amani is an 18-month Core Banking Transformation Programme undertaken by Zawadi Bank Plc to replace its 16-year-old legacy banking platform with Temenos Transact.

The Data Migration Workstream is responsible for the end-to-end migration of approximately:

- 2.4 million customer records
- 3.1 million account records
- 24 months of transaction history

The workstream covers:

✅ Data Discovery

✅ Data Cleansing

✅ Data Mapping

✅ Data Transformation

✅ Reconciliation

✅ Mock Migrations

✅ Cutover Execution

✅ Post-Migration Validation

---

## 🎯 Business Drivers

- High legacy maintenance costs
- Regulatory reporting requirements
- Digital transformation objectives
- Data quality improvement
- Product innovation capabilities
